# Hi, I'm Alex!

I'm a systems programmer, mostly writing Rust. I like to build things which solve problems, and I try to learn things from first principles in order to achieve that. I combine theory with practice to avoid tunnel vision.

### What I'm working on

- **[Rayon](https://rayon.design)**: the AI agent and MCP server, written in Rust. Before that, the rich text editor of the product.
- **[stemdark.ro](https://stemdark.ro)**: an agentic search assistant for Romanian legislation, which returns direct source citations. I built it because I needed it myself. It's being used by one user other than me in real work.
- **[cinciar.ro](https://cinciar.ro)**: a tiny little side project which implements a Wordle but in Romanian, with diacritics. I play it daily. You can even let your agents play it as it has [WebMCP](https://cinciar.ro/mcp) support.

### What I'm interested in

- Vector graphics: rendering methods, path ops, solving conflation artifacts, and more.
- AI agents: making user-facing AI more efficient in terms of latency and token usage. I also like domain-specific AIs which are super fast and cheap.
- Low-level details of software systems, from embedded drivers to performance work.

### Some things I've built

- [verg](https://github.com/AlexandruIca/verg): a vector graphics renderer in Rust, extending the font-rs approach with cubic curves, gradients and affine transformations.
- Contributions to [Graphite](https://github.com/GraphiteEditor/Graphite), an open-source Rust editor.
- [BezierContours](https://github.com/AlexandruIca/BezierContours): an implementation of Eric Lengyel's algorithm behind Slug (before it was opened), on both the CPU and the GPU.
- [Skribble](https://github.com/AlexandruIca/Skribble): a Qt app where two people can paint on the same canvas at the same time
